# ⏱ 스큐어모피즘 스탑워치

실제 스탑워치처럼 생긴 스큐어모피즘 디자인의 웹 스탑워치입니다.

## 미리보기

금속 광택 본체, LCD 디스플레이, 입체감 있는 버튼으로 구성된 클래식한 스탑워치 UI입니다.

## 기능

- **시작 / 중지** — 빨간 버튼 (실행 중엔 녹색으로 전환)
- **랩 기록** — 랩별 시간 기록, 최단 랩(초록) / 최장 랩(빨강) 자동 표시
- **재설정** — 전체 초기화
- **키보드 단축키**
  - `Space` — 시작 / 중지
  - `L` — 랩 기록
  - `R` — 재설정

## 사용 방법

별도 설치 없이 `stopwatch.html` 파일을 브라우저로 열면 바로 실행됩니다.

## 기술 스택

- HTML5
- CSS3 (그라디언트, box-shadow로 스큐어모피즘 구현)
- Vanilla JavaScript
- [Orbitron](https://fonts.google.com/specimen/Orbitron) 폰트 (Google Fonts)
